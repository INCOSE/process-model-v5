System Requirements Definition ()
As stated in ISO/IEC/IEEE 15288:2023, [6.4.3.1] The purpose of the System Requirements Definition process is to transform the stakeholder, useroriented view of desired capabilities into a technical view of a solution that meets the operational needs of the user. See detailed description in the INCOSE Handbook v.5, page 112
