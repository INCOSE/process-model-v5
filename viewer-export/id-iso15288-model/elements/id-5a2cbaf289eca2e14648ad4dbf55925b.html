System Architecture Definition ()
As stated in ISO/IEC/IEEE 15288:2023, [6.4.4.1] The purpose of the Architecture Definition process is to generate system architecture alternatives, to select one or more alternative(s) that frame stakeholder concerns and meet system requirements, and to express this in a set of consistent views. See detailed description in the INCOSE Handbook v.5, page 118
