Design Definition ()
As stated in ISO/IEC/IEEE 15288:2023, [6.4.5.1] The purpose of the Design Definition process is to provide sufficient detailed data and information about the system and its elements to enable the imple- mentation consistent with architectural entities as defined in models and views of the system architecture.
