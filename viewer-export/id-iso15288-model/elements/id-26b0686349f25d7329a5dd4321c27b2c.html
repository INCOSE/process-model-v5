Quality Assurance ()
As stated in ISO/IEC/IEEE 15288:2023, [6.3.8.1] The purpose of the Quality Assurance process is to help ensure the effective application of the organization's Quality Management process to the project. See detailed description in the INCOSE Handbook v.5, page 98
