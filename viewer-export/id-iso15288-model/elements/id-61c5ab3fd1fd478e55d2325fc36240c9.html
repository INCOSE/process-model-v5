Configuration Management ()
As stated in ISO/IEC/IEEE 15288:2023, [6.3.5.1] The purpose of the Configuration Management process is to manage and control system elements and configurations over the life cycle. CM also manages consistency between a product and its associated configuration definition. See detailed description in the INCOSE Handbook v.5, page 87
